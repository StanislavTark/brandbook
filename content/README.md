## С чего начать

Откройте компонент **DashboardExample** (группа «0 · Пример дашборда»): готовая страница, где цифрами отмечено, какое правило брендбука где применено. Затем — карточки группы «0 · Основы»: палитра, шрифты, отступы, тени, форматы чисел и CSS-классы в отрисованном виде.

## Разделы

1. **Цвета** — все токены с HEX, контрастом и местом применения; порядок цветов графиков.
2. **Шрифты и размерность** — гарнитура, шкала текста, отступы, скругления, размеры элементов, сетка страницы, форматы чисел.
3. **Иконки MDI** — словарь иконок со значениями.
4. **Виджеты** — показатели, кнопки, бейджи, теги, таблицы, круговые и кольцевые, бары и линейные, прогресс-бары; живые примеры — в компонентах с тем же номером группы.
5. **Стили CSS** — тема `css/theme.css` целиком и строки props для каждого виджета.
6. **Классы CSS** — классы темы с кодом и примерами применения.
7. **Переход на единый стиль** — общий чек-лист замены старых значений.

Как применять: вставьте тему из раздела «Стили CSS» в Настройки приложения → CSS; соберите страницу по сетке из «Шрифты и размерность»; каждый виджет настройте по строкам из «Стили CSS» и сверьте с примером.

## Текст и тон

- Пишите языком управленческой справки: коротко, по-деловому, без эмодзи и восклицаний.
- Над названием дашборда — рубрика `kicker` (`sp-kicker`): «Аналитическая панель · продажи». ПРОПИСНЫЕ даёт класс — в тексте пишите строчными.
- Название — `page-title` (`sp-title`), с прописной, без точки: «Продажи по регионам». Заголовки ПРОПИСНЫМИ вручную не набирайте.
- Блоки нумеруйте: `sp-num` + `sp-blk` — «1 Выполнение годового плана по дивизионам».
- Подписи плиток — коротко, с прописной: «Просроченная ДЗ», «В пределах срока». Расшифровка — в подсказку полным предложением.
- Единицы — постфиксом через пробел: «руб.», «экз.», «регионов». Крупные суммы — `1|c|/d` («48,6 млн»).
- Даты — `ДД.ММ.ГГГГ`, время — `ЧЧ:ММ`. Кавычки — «ёлочки». Значения из данных — как в данных.
- Сброс — «Сбросить», переход — «Открыть →», выгрузка — иконка `download` без подписи.

## Логотип
