# Брендбук дашбордов Insight BI

Сайт: https://stanislavtark.github.io/brandbook/ · редактор: https://stanislavtark.github.io/brandbook/admin/

- `content/*.md` — тексты разделов (Markdown).
- `data/tokens.json` — цвета, шрифты, отступы; `data/site.json` — название и вступление.
- `examples/` — живые примеры виджетов; `icons/` — иконки MDI.
